HSTU attention **backward** 当前只有 855 行 CPU 参考(`ck_hstu/example/ck_tile/18_hstu_attention/reference_hstu_attention_bwd.hpp`),**无 GPU kernel**;目标是设计+实现 GPU bwd,复用 ck_tile FMHA bwd 基建(`/root/ck/include/ck_tile/ops/fmha/` 的 PRE/MAIN kr_ktr_vr/POST 3-kernel + default policy)。

**目标芯片 = gfx950(MI350 / CDNA4)** —— 当前机器就是 gfx950,需特别注意 CDNA4 与 CDNA3(gfx942)的差异:占用率是 **ArchVGPR+AGPR 加法**(CDNA3 是 max)、MFMA 用 K-doubled 形状(32×32×16 / 16×16×32)、LDS 更大 + 64 banks + ds_read_tr 新变体。fwd 已有成套 gfx950 路径(`BUILD_HSTU_FOR_GFX95_ONLY` 宏、CMake `-fno-slp-vectorize`、`__gfx950__` 设备分支、`hstu_attention_fwd_setting.hpp` gfx95 tile),bwd 必须对齐。

**设计方案(2026-06-04 用户已批准,U1–U4 全用默认)**:
- 文档:`/root/workspace/hstu-b1052-report/hstu-bwd-design-20260604.html`(图文并茂版)+ `/tmp/hstu-bwd-design/DESIGN.md`(源)。已过双 review,P0=0,**风险闸门 = M1**(batched+SiLU+no-mask+bf16 端到端对拍,一次性验 FMHA policy 复用 + 留 g 的 VGPR)。
- U1 不做 dbias(Problem 留 `BiasEnum=NO_BIAS`+`BiasDataType` dummy 是复用 default policy 的硬前提)· U2 dQ 默认 atomic(两路都过 POST,因 dq 是 bf16/fp16 需 float dq_acc→convert)· U3 SiLU/bf16/hdim{64,128}/batched→jagged→group 优先 · U4 nhead_ratio=1(无 GQA)。
- 关键正确性点:激活默认 SiLU→重算 S 取 dsilu、masked-out 必须**显式置 0**(`dsilu(0)=0.5`,禁 -inf);softmax 路 LSE=−inf 需 `get_validated_lse` NaN 守卫;scale 两套 `alpha`(QK,STAGE2头+dQ/dK尾,dV不吃)+ `scale_p`(折进 p/g,softmax 不用),softmax `exp(S−LSE)` 别重复乘 scale。
