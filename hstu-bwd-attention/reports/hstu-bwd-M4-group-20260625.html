HSTU Attention Backward — M4（group 模式）：每组各自的超参，一次 launch 跑完

M4 让 bwd 支持 group HSTU——group 是 jagged 的超集:同样的 packed [1,ΣL,h,d]+cu_seqlens(直接复用 M3 寻址)外加每组各异的超参(scale_p / window / contextual / min_full / max_seqlen)。难点在 per-group window 无法编译期定 kUseLocal,故镜像 fwd 同时实例化双 pipeline、运行时选。本文行号锚定 commit 3573f083;末尾并讲紧随的 M4b 修复(180a8acb):causal=0+num_target 静默漏掩码。

读者：要 review group 路径与 P1-1 修复的工程师（group=jagged 超集，关键术语配一句白话）
TL;DR — 一句话看懂 M4

M4 = group = jagged + per-group 超参。token 布局、offset 寻址、float dq_acc atomic 累加全部沿用 M3;唯一新增的是「每组各自一套超参」——以 i_group = i_batch / num_batch_per_group 从 5 个 per-group device 指针取数(alpha 仍是全局单标量、num_target 仍 per-batch)。

最精妙处:per-group window 让 kUseLocal 无法在编译期固定(同一 launch 里有的组开窗、有的不开)。解法镜像 fwd:专用 group kernel 同时实例化 with-local 与 without-local 两条 pipeline(同 kUseCausal),kernel 内运行时按 window>0 二选一。no_group kernel 一行不改,零回归。

4  M4b 修复：causal=0 + num_target 静默漏掩码（P1-1）

M4 落地后,review 抓到一个跨所有模式的静默缺陷 P1-1,在紧随的 commit 180a8acb(M4b)以一行区域修掉。行号锚定该 commit 的 hstu_attention_no_softmax_bwd_pipeline.hpp。

症状: causal=0 + num_target>0 + window=0 时,bwd 的 target 区该掩没掩 → 梯度错(batched dQ 误差高达 1.160、group 2.180),且不 throw、不报错,纯靠对拍才暴露。

根因:编译期 gate 把掩码整段删了 分析

  • STAGE2(:413)负责把 masked-out 位置的 p/g 置零(SiLU 路 silu(0)*scale_p=0 但 dsilu(0)=0.5≠0,必须显式清)。
  • 旧代码外层用 编译期 if constexpr(FmhaMask::IsMasking) gate。而 NoLocal 把 IsMasking = kUseCausal——causal=0 时 IsMasking=false,这一整段置零被编译期删除。
  • 但 num_target>0 使 max_uih_len = seqlen − num_target < seqlen,target 区仍需掩码。reference 是无条件套 IsTokenPairInsideMask 的 → bwd 与 reference 不一致 → 静默错梯度。

修法:gate 从编译期挪到运行时 mask.IsEdgeTile 改动

  • 唯一改动:去掉外层 if constexpr(FmhaMask::IsMasking),直接以运行时 if(mask.IsEdgeTile(...)) 作门(:428);内部 set_tile_if(p/g, 0, !IsTokenPairInsideMask) 不变(:431-437)。
  • 对齐 fwd / reference:fwd 本就运行时 if(!IsTokenPairInsideMask),reference 无条件套。本修使 bwd 与两者语义一致。IsFullTileInsideMask 两个 causal 分支本就把 target tile 标为 edge,IsTokenPairInsideMask 非 causal 分支在 clamp 区已正确掩——门一开,target 区即被逐像素正确置零。
  • 纯 no-mask 不变慢(关键):IsEdgeTile 对「完全在 mask 内」的 tile 返 false → 不做逐像素扫描。tile 整除的纯 no-mask → 所有 tile full-inside → 零 set_tile_if 扫描,仅每 Q-tile 多一次廉价整数比较。
  • 一处修、三模式齐受益:batched / jagged / group 都走这条共享 SiLU pipeline,改一行区域三模式同源修复。
hstu_attention_no_softmax_bwd_pipeline.hpp:418-439 (commit 180a8acb) — gate 从编译期挪到运行时// P1-1 fix: gate on the RUNTIME mask.IsEdgeTile, NOT compile-time // FmhaMask::IsMasking. NoLocal sets IsMasking=kUseCausal, so with causal=0 the // old `if constexpr(IsMasking)` deleted this block entirely -- yet num_target>0 // still requires masking the target region ... if(mask.IsEdgeTile( seqlen_q_step, k_origin.at(number<0>{}), number<kM0>{}, number<kN0>{})) { auto is_masked_out = [&](auto tile_idx) { const int row = seqlen_q_step + tile_idx.at(number<0>{}); const int col = k_origin.at(number<0>{}) + tile_idx.at(number<1>{}); return !mask.IsTokenPairInsideMask(row, col); }; set_tile_if(p, type_convert<AccDataType>(0.0f), is_masked_out); set_tile_if(g, type_convert<AccDataType>(0.0f), is_masked_out); }
修后对拍(bf16,原 FAIL→现 PASS): A) batched causal=0 -targets=8 dQ 1.160 → 7.6e-6;E) group causal=0 -g=2 -targets=8,24,0,16 dQ 2.180 → 2.0e-3;jagged per-batch targets PASS;纯 no-mask 仍 PASS。测试套件升级为 causal=0×因子交叉矩阵(+12 个 M4b-cross case),全 PASS、未发现新缺陷;套件总 46 / pass 45 / fail 0 / skip 1,exit 0。(出处:fix-P1-1-done.md / candidates.jsonl M4b-fix-causal0-target)
教训(P1-1 式覆盖洞): 测试矩阵长期只测对角线——causal=1 配因子、causal=0 不配,从没交叉 causal=0 × num_target。这正是 IsMasking=kUseCausal 这类「非 causal ⟹ 无需掩码」的编译期假设藏身处。新特性必须做 causal × 因子 交叉覆盖,而非只测对角线。M4b 已把 12 个交叉 case 永久纳入回归。

5  设计动机小结

  1. group = jagged 超集,最大化复用:token 布局 / offset 寻址 / dq_acc atomic 全沿用 M3,只在「per-group 取数」与「双 pipeline 选择」长新逻辑——契约(M0 已冻结字段)一次填满,零结构重构。
  2. 双 pipeline + 运行时选,而非编译期 fan-out:per-group window 让 kUseLocal 无法编译期定;因 bwd pipeline 只烘 FmhaMask::IsMasking,只需两条仅 Mask 不同的 pipeline,if(window>0) 运行时选(镜像 fwd)。causal 仍编译期(group 间统一)。
  3. 直接实例化、no_group 零回归:group entry 不走 extern-template 文件,只编 SiLU causal×{local,nolocal};no_group kernel 一行不改。
  4. 全异构对拍验真:用「window/context/minfull/attn_scale/num_target 各组各异」+ g4 singleton 交叉验证——任一 per-group 取数错都会暴露大误差,实测舍入级证明真按 i_group 取数。
  5. gate 用运行时谓词,不用编译期类型假设(M4b 教训):掩码该不该做是数据(num_target)决定的运行时事实,不该烘进编译期 IsMasking。运行时 IsEdgeTile 门既正确又不拖慢 no-mask,且对齐 fwd/reference。
