CK · HSTU Backward · M2 代码改动 review

HSTU Attention Backward — M2（HSTU 5 因子 mask）：保守找 tile，逐像素判真假

M2 在 M1 的 SiLU + batched + bf16 + hd64 路径上接入 HSTU 的 5 因子 mask（causal / window / contextual / min_full / num_target 及其组合）。核心手法是「纯加」——给 4 个 HSTU mask 结构体各加两个 bwd 专属成员，不动 fwd 一行；正确性靠 STAGE2 逐像素置零保证，而非靠 Y-range 收紧。所有引用以 git show 9d129c88:<file> 行号为准。

读者：要 review bwd mask 接入的工程师（mask 几何与对拍口径配白话）
TL;DR — 一句话看懂 M2

M2 = 给反向加 mask。M1 的 SiLU MAIN/POST 流水线已能算 dV/dK/dQ，但全是「无 mask 全连接」；M2 把 HSTU 的 5 个 mask 因子接进来。设计上把问题拆成两层：GetTileRangeAlongY 先返回保守超集（整列 Q 扫描），IsEdgeTile 标出「不完全在 mask 内」的边缘 tile，再由 pipeline STAGE2 对边缘 tile 逐像素 set_tile_if(p,g ← 0, !IsTokenPairInsideMask)。正确性只依赖逐像素判定，Y-range 收紧留作 perf。

因 SiLU 路径不能用 −inf（dsilu(0)=0.5≠0，−inf 会变 NaN），masked 位置必须显式写 0——这是 M2 最易踩的坑。落地前先过一道离线穷举校验器（185932 次断言全 GREEN）确认超集成立，再做对拍。

3  逐文件 review（为什么这样改）

① hstu_block_masking.hpp — 给 4 个 mask 结构体加 bwd 成员 改动

  • 方案 A「纯加」:给全部 4 个 HSTU mask struct（Cross/Self × With/No Local）各加两个成员,fwd 已有成员一行不动。Self-with-local 在 :524/:531、Self-no-local :841/:848、Cross-with-local :272/:280、Cross-no-local :693/:700。
  • GetTileRangeAlongY(i_x, number<YTile>, number<XTile>) = KV-block→attend 的 Q 行范围,是 fwd GetTileRangeAlongX 的转置。M2 返回连续保守超集 (0, seqlen)（self;cross 为 (0, seqlen_q)）——即整列 Q 全扫描。标 CK_TILE_HOST_DEVICE 以便离线校验器在 host 侧直接调。
  • IsEdgeTile(top, left, number<TileHeight>, number<TileWidth>) := !IsFullTileInsideMask(top, left, number<TileWidth>, number<TileHeight>)——「不完全落在 mask 内 ⇒ 是边缘 tile ⇒ 需逐像素查」。注意 IsFullTileInsideMask 的参数序是 (top, left, Width, Height),IsEdgeTile 转发时按此序传(易错点)。
  • 5 因子的几何全压在已存在的 IsTokenPairInsideMask(row,col) 里:contextual 把行列号钳到 max(idx-contextual+1,0)、causal 要 row_id>col_id || row==col、window 要 row_id-col_id≤max_attn_len、min_full 在 row_id≥max_id-min_full 时放开 window、num_target 经 max_id 影响钳制(self-local :445-490)。bwd 不复制这套逻辑,只复用它。
  • HstuBlockMasking<kIsCrossAttention,kUseCausal,kUseLocal>::Type（:856-866）是 dispatch 选型用的 trait;工厂 make_hstu_self_attention_block_mask_with_local（:891）/_without_local（:918）按签名构造实例。
hstu_block_masking.hpp:521-537 — Self-with-local 的两个 bwd 新成员（其余 3 个结构体同形）// --- bwd additions (M2, DESIGN §3.1) --- template <index_t YTile, index_t XTile> CK_TILE_HOST_DEVICE constexpr auto GetTileRangeAlongY(index_t /*i_x*/, number<YTile>, number<XTile>) const { return ck_tile::make_tuple(0, seqlen); // 保守全-Q-扫描超集 (§8.2-R3) } template <index_t TileHeight, index_t TileWidth> CK_TILE_DEVICE constexpr bool IsEdgeTile(index_t i_tile_top, index_t i_tile_left, number<TileHeight>, number<TileWidth>) const { return !IsFullTileInsideMask( i_tile_top, i_tile_left, number<TileWidth>{}, number<TileHeight>{}); // 注意 W/H 参数序 }

4  设计动机小结

  1. 纯加不改 fwd:bwd 所需的 GetTileRangeAlongY/IsEdgeTile 作为新成员加进 4 个 mask 结构体(方案 A),fwd 路径零风险;5 因子几何完全复用 fwd 的 IsTokenPairInsideMask,不重写一份易漂移的逻辑。
  2. 保守超集 + 逐像素兜底,把正确性与性能解耦:GetTileRangeAlongY 先给一定不漏的全 Q 扫描,正确性只由 IsTokenPairInsideMask 决定;Y-range 收紧、tile 级 first-split 都纯属 perf,不影响数值。
  3. SiLU 路径显式写 0,不用 −inf:dsilu(0)=0.5≠0 且 −inf 经 SiLU 产 NaN;清 p、g 后 ds=dp·g 自动归零,等价 reference dS=0。
  4. 离线穷举做硬前置闸:185932 次断言确定性证明超集成立,堵住对拍可能漏的 silent-wrong;落地顺序固定为「先校验器 GREEN,再对拍」。
  5. 口径对齐 reference:min_full 钳制(eff_min_full)、per-batch num_target 复刻 CPU 参考,并修掉 harness/reference 同源的 num_targets OOB,才让对拍数值真正可比。
